# 🎬 TMDB Exploratory Data Analysis (EDA)

An end-to-end Exploratory Data Analysis (EDA) project on the TMDB (The Movie Database) dataset. This project analyzes movie trends, ratings, budgets, revenues, genres, directors, and other key insights using Python and data visualization libraries.

## 📌 Project Overview

The objective of this project is to explore the TMDB movie dataset and uncover meaningful insights through data analysis and visualization.

The notebook:
- Loads data from a SQLite database (`movies.db`)
- Cleans and prepares the data
- Performs exploratory data analysis
- Generates visualizations
- Summarizes key business insights

## 📊 Exploratory Data Analysis

The notebook answers the following questions:

1. Which genres have the most movies?
2. Does a higher budget generate higher revenue?
3. How are movie ratings distributed?
4. Revenue distribution by genre
5. Average runtime over different decades
6. Franchise vs Standalone movie performance
7. Best month to release a movie
8. Top directors by average rating
9. Most frequently appearing actors
10. Correlation between numerical features
11. Movie release trends over the years
12. Highest Return on Investment (ROI) movies

## 🔍 Key Insights

- Drama and Comedy are among the most common genres.
- Higher budgets generally lead to higher revenues, though exceptions exist.
- Most movies receive ratings between 6 and 8.
- Certain genres consistently generate higher revenues.
- Movie production has increased significantly over recent decades.
- Successful franchises often outperform standalone films.
- Some low-budget movies achieve exceptionally high ROI.
